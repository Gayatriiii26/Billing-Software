# 🧾 Billing Software

A web-based billing and management application developed to simplify daily billing operations for a tiles business. The system helps manage customers, products, invoices, GST calculations and sales reports through a simple and user-friendly interface.

## 📌 Project Overview

**Billing Software (Tiles billing system)** is designed to make business billing faster, easier and more organized. It provides a centralized platform for managing billing activities, maintaining records and generating invoices.

## ✨ Key Features

- **Dashboard:** Overview of important business information.
- **Customer Management:** Add, view and manage customer details.
- **Product Management:** Maintain product information and pricing.
- **Invoice Management:** Create and manage customer invoices.
- **GST Calculation:** Automatic CGST and SGST calculations.
- **Sales Reports:** View and track sales information.
- **User Profile:** Manage user profile information.
- **Settings:** Manage application settings.
- **Database Integration:** Store and manage business data using MySQL.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1. Install Requirements

- XAMPP
- PHP
- MySQL
- Composer

### 2. Clone the Repository

```bash
git clone https://github.com/Gayatriii26/tiles-billing-system.git
```

### 3. Move Project Folder

Place the project inside your XAMPP `htdocs` directory.

```text
C:\xampp\htdocs\tiles-billing-system
```

### 4. Start XAMPP

Start the following services:

- Apache
- MySQL

### 5. Configure Database

- Open phpMyAdmin.
- Create the required database.
- Import the project's SQL database file.
- Configure the database connection details in the appropriate configuration file.

### 6. Install Dependencies

Open the project terminal and run:

```bash
composer install
```

### 7. Run the Application

Open your browser and visit:

```text
http://localhost/tiles-billing-system/login.php
```
